# Hukuki metin taslakları (KVKK)

> ⚠️ **TASLAK — avukat incelemesi olmadan yayınlanmaz.** Bu dosyalar hukuki tavsiye değildir; uygulamanın
> GERÇEKTE yaptığını anlatan çalışma taslaklarıdır. Sağlık verisi (özel nitelikli) ve 18 yaş altı sporcu verisi
> işlendiği için avukat incelemesi **önerilmez, zorunludur**.

| Dosya | Amaç |
|---|---|
| `veri-isleme-envanteri.md` | Şemadan çıkarılan gerçek veri envanteri (amaç, hukuki sebep, saklama, aktarım) |
| `aydinlatma-metni.md` | KVKK m.10 aydınlatma metni taslağı |
| `acik-riza-saglik.md` | Sağlık verisi için açık rıza metni taslağı |
| `ticari-ileti.md` | Ticari elektronik ileti izni / İYS notları |
| `taahhutname.md` | Salon kullanım taahhütnamesi taslağı |
| `avukat-sorulari.md` | Avukata sorulacak açık noktalar |

Uygulamadaki onam metin sürümü `lib/onam-metinleri.ts` içindeki `ONAM_METIN_SURUMU` değeridir; metin değişince
sürüm de değişmelidir (onam kayıtları hangi metne verildiğini saklar).
